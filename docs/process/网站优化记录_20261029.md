## 实际验证结果

浏览器：本机 Google Chrome（Playwright 驱动）。检查 1440px 桌面以及 375、414、768px 窄屏。

- 核对到 3 张植物卡、8 项重点解码、16 项序位与 17 项微量成分。
- 产品图库切换、筛选结果 3/4/1、植物到成分、成分到配方均通过。
- 详情 Enter 打开、Esc 关闭、焦点回位与面板内焦点约束通过。
- #ingredient=panthenol 等成分链接、#plant=rhodiola 植物链接及浏览器前进后退通过。
- 375/414/768px 页面均无横向溢出；375/414px 抽屉底部对齐、移动导航及关闭后解锁滚动通过。
- 禁用 JavaScript 后，植物卡、8 项成分折叠详情、完整配方仍可阅读。
- 未发现浏览器脚本异常或本地 HTTP 资源请求失败。
