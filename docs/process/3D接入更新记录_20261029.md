# 3D 预览接入更新

- 默认进入深色影棚，保留植物柔光切换。
- 鼠标在模型画布上滚动时缩放，近远范围有限制；画布外仍可正常滚动页面。
- 用三叶鬼针草、千日菊、红景天的瓶身热点替换材质标注，默认显示。
- 每个热点展示老师提供的植物插画、拉丁名及配方第 3 / 5 / 9 项说明，可跳转主站对应成分。
- 主站首页精华图、产品区图片和“进入精华液 3D 影棚”按钮，统一进入 3d/index.html。
- 3D 页面可返回主站产品区；所有路径均为相对路径，兼容本地文件和 GitHub Pages 项目路径。
- 预览可部署文件同步至网站 3d/；开发源码与 npm 依赖不放入部署目录。工作流已包含 3d/。

源码继续位于项目的 3D精华预览/。修改后执行 node tools/build.cjs，再执行 node tools/publish-local.cjs 同步主站。

本次未重新生成模型几何或旋转视频；原始模型和第一版视频保留。当前交互以主站 3d/index.html 为准。
