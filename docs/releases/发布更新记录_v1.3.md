## 官网观察与采用范围

本次实地浏览官网并记录可见元素的计算样式，原始记录和截图在项目根目录 `output/字体与产品区优化_v1.3_20261029/`。

- [伊索中国官网](https://www.aesop.com.cn/)：可见中文正文、链接声明 `SuisseIntl-Regular, sans-serif`，常见字号约 14 px，正文与按钮用不同字重。参考其清晰的无衬线正文、克制的层级和留白。
- [莱珀妮中国官网](https://www.laprairie.com.cn/)：本次成功读取的是地区选择、隐私及界面文案；其样式声明 `"La Prairie", sans-serif`，可见正文约 14 px / 22 px，标题约 24 px / 32 px。参考轻字重与行距组织；未据此声称检查了全部产品页面。
- [海蓝之谜中国官网](https://www.lamer.com.cn/)：可见菜单声明 `font, chineseFont`，约 14 px。此次证据不足以判断真实字体名称，因此未将它作为字体识别结论。

计算样式记录的是 CSS 声明，中文字符可能由回退字体显示，不能据此认定中文实际字形来自品牌字体。本项目没有提取或分发品牌专有字体。

## 实施规格

- 主标题：桌面最大 60 px / 1.45，常规字重 400；手机约 34–44 px / 1.5。
- 正文：主要介绍桌面 15–17 px、手机 15 px；辅助说明使用更小字号；按信息层级区分。
- 字体：`CFH Sans` 为 CSS 别名，文件实际来自 Noto Sans SC，保留名称和许可证元数据。系统回退为苹方、微软雅黑、Arial、sans-serif。
- 字体原始来源：[Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，许可证 SIL Open Font License 1.1，随网页保留 `assets/fonts/OFL.txt`。
- 本地可变 WOFF 子集约 238 KiB，覆盖当前 HTML、data.js、app.js 文字及 ASCII，共 655 个映射字符。它保留字重变化，不依赖外部字体服务。
- 若后续增加文案，应更新字体子集。当前生成脚本位于 `output/字体与产品区优化_v1.3_20261029/tools/subset-font.py`，原始字体与构建记录在同级输出目录；缺少字符时浏览器仍会使用系统回退字体。
- `typography.css` 单独控制本轮字体更新，并已加入 Pages workflow 的公开文件复制清单。
