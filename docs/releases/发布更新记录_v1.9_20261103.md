# 草肤荟网站 v1.9 更新记录

日期：2026-11-03
版本：v1.9  2026-11-03-v1.9

## 本轮目标

本轮根据使用反馈重新设计植物图鉴和成分解码，同时调整首页产品实物图的说明位置。v1.8 原目录与发布包保留不覆盖。

## 植物图鉴

- 卡片基础信息只保留“植物识别”和“植物背景”两组事实。
- “配方定位”保留为单独的序位标记，用于连接植物图鉴与配方序列。
- 删除卡片中的“植物与提取物”和“这份配方中的位置”说明，避免植物信息与配方信息重复。
- 详细阅读区改为三栏：形态与分布、植物成分线索、护肤研究观察。
- 删除过多的边界段落，只保留简短资料来源链接；内容改为客观描述，不使用“用户稿”“现有稿件”等过程性措辞。
- 桌面端三栏并列，移动端自动转为纵向阅读；植物插画直接加载，保证进入图鉴时可见。

## 首页 50 mL 实物

首页主视觉的 50 mL 说明从图片上方的覆盖层移到图片下方，形成独立说明栏，瓶身、礼盒和说明文字不再相互遮挡。产品章节的 50 mL / 10 mL 规格对比保持不变。

## 成分解码

- 成分卡片改为“成分身份—一般角色—资料来源”的信息结构。
- 删除“最容易误解什么”和成分卡内的配方位置说明。
- 弹窗同步删除上述两类字段，仅保留成分名称、英文名、一般角色、成分身份和资料来源。
- 16 项配方原始顺序仍保留在独立的配方序列区，避免丢失定位功能。
