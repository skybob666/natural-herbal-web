# 草肤荟网站 v1.10 更新记录

日期：2026-11-03
版本：v1.10 / 2026-11-03-v1.10

## 本轮目标

根据页面使用反馈，缩减重复导览、强化植物选择与成分解码的实际阅读价值，同时整理首页实物图和来源区的信息层级。v1.9 及此前版本均保留，不覆盖。

## 植物图鉴

- 删除“三步探索”导览及相关弹窗路径。
- 三株植物均改为同等入口的选择卡，桌面端采用轻度叠放的卡片排布，移动端改为纵向列表。
- 初始状态只显示选择提示；选中一株植物后，显示植物识别、植物背景和配方定位。
- 植物科普不再随卡片直接铺开，改为“查看植物科普”按钮主动展开。
- 每株植物展开后统一呈现三段内容：植物形态与背景、植物成分线索、护肤研究观察。
- 切换植物时，上一株植物的科普内容自动收起，阅读焦点保持清楚。

## 首页与配方稳定说明

- 首页实物图的舞台底色改为与照片背景一致，取消右侧装饰印章，减少图片两侧的视觉裁边感。
- 50 mL 信息继续保留在实物图下方的独立说明栏，不覆盖瓶身和礼盒。
- “配方稳定”改为一个完整的信息单元：说明原料质量、生产卫生、pH、包装密封和配方辅助体系共同参与水相精华的稳定。
- 1,2-己二醇与对羟基苯乙酮保留为进入该主题的配方阅读线索。

## 成分解码

- 页面仅保留 8 项具有明确名称、角色与资料来源的重点成分卡。
- 16 项配方序列继续完整展示；没有展开资料的名称改为静态节点，不会弹出空泛详情。
- 重点成分弹窗保留成分身份、一般角色、资料来源与对应资料链接。
- 来源区调整为资料说明，删除重复的阅读边界类文字。

- 运行 `node scripts/build-static.cjs` 同步静态 HTML。
- 使用本地 HTTP 服务检查 1440×1000 桌面视口和 390×844 移动视口。
- 检查三株植物的选择、科普按需展开、切换自动收起、无内容配方节点不弹窗、稳定性卡片内容、首页图片底色与控制台错误。
