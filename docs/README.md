# 文档目录说明

这里保存课程项目的内容来源、科普资料、版本记录和开发说明。文档按用途分组，方便提交课程作业时查阅。

- `releases/`：v1.0—v1.17 的发布定版与更新记录。
- `sources/`：产品包装、植物图鉴与科普内容的来源核对资料。
- `process/`：3D 接入、页面优化、技术栈、开发日志与 AI 使用记录。
- `archive/previous-root/`：从仓库根目录整理下来的旧记录、旧素材和旧代码备份。

`archive/previous-root/` 仅用于保留项目过程，不参与网站运行；当前网站只读取根目录入口、`assets/`、`3d/` 和 `scripts/`。
