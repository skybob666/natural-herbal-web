## 与包装资料的对应规则

1. 包装/公众号配方记录提供的是“某植物提取物”名称和序位。
2. 物种来源提供的是该植物的分类、分布或形态背景。
3. 两类资料只能在“名称关联”这一层相接：网页不得把植物学资料外推成产品的实际提取部位、工艺、浓度或实测结果。
4. 三张插画均来自品牌视觉素材，页面已显著说明“用于关联名称，不作为植物鉴定依据”。
