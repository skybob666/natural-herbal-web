# 草肤荟成分探索馆 v1.5 发布说明

发布日期：2026-11-03  
发布类型：本地冻结包，待人工确认后上传 GitHub Pages。

## 本版重点

- 以三张植物卡为入口，完成“看植物 → 读提取物 → 找配方位置”的连续学习路径。
- 植物卡补齐识别、背景、提取物关系和配方位置；品牌插画已明确标为非鉴定依据。
- 八项重点成分统一为五层阅读结构，且不把一般资料外推为产品实测功效。
- 3D 热点从“直接成分解码”改为“从植物档案开始”。
- 精华液主图区移除带手写标注的规格照片，改用干净正面实拍，规格继续以网页文本显示。

## 发布前已验证

- `node --check data.js`
- `node --check app.js`
- `node --check scripts/build-static.cjs`
- `node scripts/build-static.cjs`
- 3D 打包与同步：`node build.cjs`、`node publish-local.cjs`
- 桌面与 390 px 移动端：三步路径、植物/成分弹窗、配方高亮、无横向溢出、3D 植物热点链接。
