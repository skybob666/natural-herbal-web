# 线上网站锐评整改说明 v1.5

更新日期：2026-11-03  
适用范围：`初版网站` 静态站与 `/3d/` 交互预览。

## 本次整改目标

本次只落实《线上网站锐评与赶超清单》指出的优先问题：把“植物名索引”改为可完成的学习路径。保留现有单页结构、实拍素材、3D 外观展示与静态技术路线，不新增商品购买、算法推荐、额外页面或新的 3D 模型。

## 锐评项与落地位置

| 锐评问题 | v1.5 改动 | 核对位置 |
|---|---|---|
| 植物卡片缺少科学内容 | 三张卡片均补齐“植物识别、植物背景、植物与提取物、配方位置”四层；插画明确标注为品牌视觉素材，不能用于鉴定。 | 首页“在配方里，遇见植物” |
| 植物到配方的路线不完整 | 卡片打开植物档案；“下一步”进入对应提取物；再定位 16 项配方中的序位。3D 热点也先回到植物档案。 | `#plant=…`、`#ingredient=…`、`#formula` |
| 八项成分解释不均衡 | 每项补为“它是什么、通常做什么、最容易误解什么、在这份配方中的位置、资料说明与解读边界”五层。 | 首页“成分解码” |
| 规格图区有手写干扰 | 主图区改用干净的精华液正面实拍；50 mL / 10 mL 以网页文字保留。 | 首页“从一滴精华开始” |
| 来源不能只留在线链接 | 新增植物学资料摘录、原始来源记录与测试记录模板；每条保留标题、网址、访问日期、使用范围。 | `docs/` |
| 移动端信息过密、触达面积不足 | 植物卡片插画高度压缩；主操作、3D 热点和常用控件维持至少 44 px 的触达面积。 | `styles.css`、`3d/preview.css` |

## 内容边界

- 植物学来源只支持物种识别与背景，不等同于该产品有效性证明。
- 包装与公众号资料没有提供提取部位、提取工艺或浓度，因此页面统一写为“资料未说明”，不作补充推断。
- 配方序位只用于定位，不能换算为含量或功效强弱。
- 两位真实同学的任务测试尚未开始；`三步探索同学测试记录_待填写.md` 仅是待执行模板，不可作为已经完成测试的证据。

## 本地验证

本版构建后应执行：

```powershell
node scripts/build-static.cjs
node --check data.js
node --check app.js
node --check scripts/build-static.cjs
```

3D 预览更新后应执行：

```powershell
Set-Location ..\3D精华预览\tools
node build.cjs
node publish-local.cjs
```
