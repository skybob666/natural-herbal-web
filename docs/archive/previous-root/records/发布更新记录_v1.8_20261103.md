# 草肤荟网站 v1.8 更新记录

日期：2026-11-03  
版本：v1.8  2026-11-03-v1.8

## 本轮依据

本轮修改按《v1.7复审与修改清单_20261103》执行。v1.7 原目录与发布包不覆盖，作为历史版本保留。

## 已完成的整改

1. 植物图鉴的信息层分开处理：事实层只保留识别、背景、提取物对应关系和配方序位；详细科普层保留形态与分布、植物成分线索、护肤研究观察及阅读边界，减少同义重复。
2. 详细科普改为原生 `details` 结构。桌面端默认展开，屏幕宽度不超过 600 px 时默认收起，用户仍可按需打开；移动端事实层改为 2×2 网格，缩短首屏卡片高度。
3. 三步导览由普通块改为真实按钮。第 01 步打开首个植物档案，第 02 步打开其对应提取物，第 03 步定位配方序位；用户在查看某一植物后，导览会沿用当前植物。
4. 详情弹窗操作区使用 `position: sticky` 吸附在滚动区域底部，避免内容较长时“下一步”按钮离开可视区域。
5. 删除详情关闭按钮的 `autofocus`，弹窗打开后把焦点放到可滚动内容区；可见焦点环统一为绿色 2 px，避免红色焦点框干扰画面。
6. 重点成分卡增加一句话阅读钩子；配方序列中的重点成分取消大面积浅色底，仅保留悬停与定位反馈，降低与成分卡的重复视觉重量。
7. 1,2-己二醇条目补充“能确定 / 不能确定”说明：可确认配方记录中的名称与序位，不能由当前资料确认添加量、完整防腐体系或整瓶产品稳定性。

## 图片与证据边界

- 植物图鉴继续使用老师提供的三张本地植物插画，仅作名称关联和课程展示，不作为植物鉴定证据。
- 原公众号稿件中提到但未随项目提供的机制图、人体数据图、皮肤扫描图没有用生成图片替代；页面明确保留“待核验 / 待补原始资料”边界。
- 植物页面只讨论红景天、三叶鬼针草和千日菊自身及其提取物阅读线索，不设置与其他抗老成分的对比栏目。

## 验证方式

- 运行 `node --check data.js`、`node --check app.js` 和 `node scripts/build-static.cjs`。
- 使用本地 HTTP 服务检查桌面端与移动端首屏、植物科普折叠、三步导览、弹窗底部操作区、焦点位置、图片加载和 hash 路由。
- 检查结果与截图保存于项目根目录 `output/20261103-v1.8-qa/`。
