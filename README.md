## 查看网站

直接打开本目录的 `index.html`。图片和主要交互均使用相对路径，不依赖在线字体、CDN 或第三方脚本。

本地 HTTP 预览：在本目录打开终端，执行 `py -m http.server 8137 --bind 127.0.0.1`，再打开 http://127.0.0.1:8137/ 。

## 修改内容

`data.js` 为成分与植物的单一数据源。更改后运行：

```powershell
node scripts/build-static.cjs
```

该命令将数据同步到 `index.html` 的标记区块，使无 JavaScript 阅读内容同步更新。不需要 npm 安装依赖。

- `index.html`：页面正文与预生成的静态内容
- `styles.css`：视觉规范、响应式样式、详情弹窗
- `typography.css`：v1.3 中文字体、文字层级与各屏幕尺寸排版
- `app.js`：增强交互、导航、筛选和 hash 状态
- `assets/`：网页图片、自制叶片 favicon、本地字体及其 OFL 授权
- `docs/`：课程过程材料，当前版本以带日期的记录为准；早期示例文档作历史记录保留
- `.github/workflows/pages.yml`：GitHub Pages 自动部署，发布入口、两份 CSS、脚本、assets 与 3d
