# 草肤荟 · 植物成分探索馆

课程网站发布版 v1.17（2026-11-07）。

本站围绕草肤荟“植物草本御肤”系列的两款实物展开：50 mL 植物草本御肤精华液与 50 g 植物草本御肤精华面霜。页面把产品实拍、包装可读信息、植物图鉴与配方条目组织在同一套阅读路径中。

## 页面内容

- **首页**：系列概览、两款产品入口与产品组合介绍。
- **御肤系列**：
  - 精华液：正视实拍、规格、使用说明与 3D 影棚入口；
  - 面霜：仅展示正视实拍，并整理包装上的规格、使用说明与植物成分线索。
- **植物图鉴**：红景天、三叶鬼针草、千日菊三张可选择的植物卡；选中后可继续阅读植物背景、成分线索和护肤研究观察。
- **成分阅读**：保留完整配方顺序；其中 8 项配方条目可筛选和展开阅读，查看其常见角色、资料来源与关联植物。
- **资料与说明**：产品包装、植物科普与公众号阅读入口。

## 如何查看

直接双击 `index.html` 即可阅读基础内容。

如需在浏览器中完整体验筛选、弹窗、页面锚点和 3D 入口，可在本目录打开 PowerShell 后运行：

```powershell
.\启动本地预览.ps1
```

随后打开脚本提示的本地地址。也可以执行：

```powershell
py -m http.server 8137 --bind 127.0.0.1
```

再访问 `http://127.0.0.1:8137/`。

## 主要文件

| 文件或目录 | 作用 |
| --- | --- |
| `index.html` | 页面结构，以及预先生成的静态阅读内容。 |
| `styles.css` | 页面视觉、产品区、植物图鉴、成分阅读与响应式布局。 |
| `typography.css` | 本地字体和文字层级。 |
| `data.js` | 植物、成分、产品及资料链接的集中数据。 |
| `app.js` | 产品切换、植物选择、成分筛选、详情展开和页面定位。 |
| `scripts/build-static.cjs` | 将 `data.js` 中的内容同步到静态页面。 |
| `assets/` | 产品实拍、植物图、字体和网页图标。 |
| `3d/` | 精华液 3D 影棚预览页面与模型资源。 |
| `docs/` | 资料整理、内容核对与过程记录。 |
| `.github/workflows/pages.yml` | GitHub Pages 发布流程。 |

仓库根目录只保留当前线上版本运行所需的文件。课程过程资料按用途放在 `docs/releases/`、`docs/sources/` 和 `docs/process/`；早期根目录文件统一保存在 `docs/archive/previous-root/`，既保留迭代痕迹，也不会干扰网站发布。

## 修改内容后的同步方法

植物、成分或产品信息优先在 `data.js` 中修改。修改后，在本目录运行：

```powershell
node scripts/build-static.cjs
```

该操作会更新 `index.html` 中的静态阅读内容，保证未启用 JavaScript 时也能阅读页面主体。

成分阅读区使用 `expandable: true` 标记可展开的条目。这一标记仅用于页面阅读交互，不表示该成分是配方中的重点、主打成分或功效结论。

## 当前版本说明

- 面霜产品区只使用 `assets/images/cream/front.jpg` 正视实拍，不再展示其他角度图片。
- 成分阅读区显示“8 项可展开阅读的配方条目”；完整配方顺序仍保留在页面内。
- 精华液 3D 页面由产品区入口进入，支持拖动查看和滚轮缩放。
- 所有产品图片、植物图片、字体与网页脚本均随发布包提供，基本浏览不依赖外部字体或第三方脚本。

## 发布到 GitHub Pages

仓库地址：<https://github.com/skybob666/-sky>

将本目录内的网页文件、`assets/`、`3d/` 与 `.github/workflows/pages.yml` 一并更新到仓库根目录，再在 GitHub 的 **Actions** 页面确认部署任务显示绿色 `Success`。线上地址为：<https://skybob666.github.io/-sky/>。

如果线上页面仍显示旧内容，可使用 `Ctrl + F5` 强制刷新浏览器缓存。
